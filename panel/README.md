# مخزن یکپارچه ماژول مدیریت ارشد پلتفرم حسابرو وان (Hesabro Admin Backoffice Monorepo)

این دایرکتوری به عنوان یک **Monorepo** کاملاً مستقل از هسته حسابرو وان، شامل هر دو بخش **Backend (Django REST Framework)** و **Frontend (Vue 3 + Vite)** برای مدیریت ارشد پلتفرم (Backoffice) می‌باشد.

---

## 📁 ساختار مخزن (Monorepo Directory Structure)

```text
panel/
├── backend/                       # وب‌سرویس بک‌اند جنگو (Headless REST API)
```

## 🚀 راهنمای اجرا و توسعه لوکال

### ۱. اجرای همزمان بک‌اند و فرانت‌اند با یک دستور:
در ریشه پوشه `panel/` کافی است دستور زیر را اجرا کنید:
```powershell
.\dev.ps1
```
این اسکریپت به صورت خودکار:
1. سرویس بک‌اند جنگو را روی `http://127.0.0.1:8001` اجرا می‌کند.
2. سرور توسعه Vite فرانت‌اند را روی `http://127.0.0.1:5173` بالا می‌آورد.

یا با استفاده از npm:
```bash
# اجرای جداگانه بک‌اند:
npm run dev:backend

# اجرای جداگانه فرانت‌اند:
npm run dev:frontend
```

## 🔑 حساب‌های کاربری پیش‌فرض (Seed Accounts)
پایگاه داده لوکال شامل حساب‌های آزمایشی زیر است:

| نقش (Role) | شماره همراه | کلمه عبور | دسترسی‌ها |
| :--- | :--- | :--- | :--- |
| **راهبر ارشد (SUPER_ADMIN)** | `09120000001` | `AdminPass123!` | دسترسی کامل به کلیه بخش‌ها، تنظیم پلن و لاگ‌ها |
| **کارشناس پشتیبانی (SUPPORT_AGENT)** | `09120000002` | `AdminPass123!` | جعل هویت مستأجران، تعلیق/فعال‌سازی، بدون دسترسی مالی |
| **مدیر فروش (SALES_MANAGER)** | `09120000003` | `AdminPass123!` | مدیریت افیلیت و کدهای تخفیف، درخواست تسویه |
