# 🤖 ربات خودکار ثبت گزارش کارها در فارو (WorkReport Bot)

این پروژه به صورت کاملاً مستقل و ایزوله جهت خواندن گزارش کارهای توسعه‌دهنده از فایل `project-report.md`، بررسی هوشمند موارد تکراری از روی پلتفرم فارو، و ثبت خودکار آن‌ها به صورت وظیفه (تسک) بر اساس اندپوینت‌های مستند شده در `tasks.md` پیاده‌سازی شده است.

---

## 🌟 ویژگی‌های کلیدی

1. **رابط کاربری تعاملی با Streamlit**:
   - محیط کاملاً فارسی و راست‌چین (RTL).
   - داشبورد آماری با تفکیک کل گزارش‌ها، تسک‌های آماده ثبت، و موارد تکراری.
2. **انتخاب روزهای کاری (Date Filter)**:
   - امکان انتخاب گزینشی روزها (چک‌باکس/مولتی‌سلکت) با نمایش تعداد گزارش‌های هر روز.
   - دکمه‌های «انتخاب همه» و «لغو انتخاب».
3. **بررسی هوشمند تکرارها از روی سامانه فارو**:
   - واکشی زنده تسک‌های فارو (`/api/v1/tasks/feed/` و بورد انتخابی).
   - مقایسه هوشمند عنوان و تاریخ گزارش و پیشگیری قطعی از ثبت تکراری تسک‌ها.
   - ردیابی تاریخچه محلی در دیتابیس سبک SQLite (`sync_state.db`).
4. **ربات ثبت خودکار**:
   - ثبت گروهی با نمایش نوار پیشرفت زنده (`st.progress`) و لاگ لحظه‌ای.
   - امکان اجرای تستی (Dry Run) بدون ایجاد تغییر در سرور.
   - اسلایدر تنظیم تاخیر زمانی (Rate Limit) بین درخواست‌ها.
   - امکان ثبت دستی و تکی برای هر گزارش به صورت جداگانه.

## 🚀 راهنمای راه‌اندازی و اجرا

### روش اول: اجرای با اسکریپت آماده
در ویندوز کافی است فایل زیر را اجرا کنید:
- دابل کلیک روی `run.bat` یا اجرای `run.ps1` در PowerShell.

### روش دوم: اجرای دستی با ترمینال
```bash
cd workreport
pip install -r requirements.txt
streamlit run app.py
```

## ⚙️ تنظیمات اتصال به فارو

اطلاعات اتصال را می‌توانید در فایل `workreport/.env` قرار دهید یا مستقیماً از نوار کناری برنامه در استریم‌لیت وارد کنید:

- **Base URL**: آدرس سرور فارو (پیش‌فرض: `http://localhost:8000` یا آدرس سازمان)
- **Session Cookie (`sessionid`)**: مقدار کوکی نشست کاربر در مرورگر
- **CSRF Token (`csrftoken`)**: توکن احراز هویت درخواست‌های POST
- **Bearer Token**: در صورت نیاز به هدر Authorization
