# بستهٔ اجرایی تولید آموزش فارو

این بسته بر مبنای سورس نسخهٔ `0.1.3+13` و کامیت `4086c13de71103f780841d4333bb861b5ab3de73`، در تاریخ ۲۰۲۶/۱۰/۲۵ آماده شده است.

## فایل اصلی

- [سند HTML راست‌به‌چپ و قابل جست‌وجو](FARO_VIDEO_PRODUCTION_HANDBOOK_FA.html) — پیشنهاد برای مطالعه و تحویل به تیم تولید؛ فونت داخل فایل قرار دارد و نمایش سند به اینترنت نیاز ندارد.
- [نسخهٔ Markdown قابل ویرایش](FARO_VIDEO_PRODUCTION_HANDBOOK_FA.md) — شامل تحلیل معماری، مسیرها، نقش‌ها، نقشهٔ قابلیت‌ها، برنامهٔ آموزشی و متن کامل ۴۲ سناریو با بخش‌های A تا G.

در نسخهٔ HTML از فهرست سمت راست برای رفتن به سناریو و از جست‌وجوی بالای صفحه برای محدودکردن سناریوها استفاده کنید. بخش «فهرست عنوان و توضیح کوتاه ویدیوها» یک دکمه برای کپی یک‌جای هر ۴۲ عنوان و توضیح یک‌خطی، آمادهٔ انتقال به لیست تسک یا ارائه به کارفرما دارد. هر ویدیو هم یک راهنمای کوتاه و شماره‌دار برای اجرای مسیر ضبط و یک دکمهٔ «کپی متن نریشن» دارد. جدول کامل UI هم برای جزئیات و تدوین زیر راهنمای کوتاه آمده است. با «نمایش همه» فیلتر پاک می‌شود. برای بازشدن لینک‌های شواهد، پوشهٔ `faro-flutter` باید کنار این پوشه باشد؛ نام فایل و شمارهٔ خط هر شاهد نیز درج شده است.

## وضعیت تأیید

بررسی و نگارش بر پایهٔ کد انجام شده است. برنامه در این کار اجرا نشده و هیچ ورود، ارسال، دعوت، تغییر مجوز یا بارگذاری در سرویس واقعی انجام نشده است. آزمون‌های Flutter مخزن نیز در این نوبت اجرا نشده‌اند. نتیجه‌های نوشته‌شده در سناریوها، انتظار کد هستند؛ نتیجهٔ واقعی باید در برگهٔ برداشت ثبت شود.

نسخهٔ فعلی، ابزارهای «بزودی» و کنترل‌های نمای قدیمی بدون مسیر فعال را از آموزش قطعی کنار می‌گذارد. V42 دربارهٔ فایل دانشی، به دلیل تفاوت نوشتهٔ UI و دامنهٔ endpoint، تا تطبیق با محیط واقعی برای انتشار متوقف است. مدل‌های موجود حساب، شناسه‌های رکورد و کنترل‌های پنجرهٔ چاپ سیستم هم باید قبل از ضبط مقدار واقعی داشته باشند.

## بازتولید خروجی‌ها

از مسیر `D:\Projects\Hesabro-one` با Python 3، دستور زیر را اجرا کنید:

```powershell
python .\video-training\tools\build_handbook.py
```

اسکریپت سورس را از پوشهٔ `faro-flutter` کنار همین پوشه می‌خواند و خروجی‌ها را فقط در `video-training` می‌سازد. منابع نگارش در `tools/scenario_data.py`، `tools/report_intro.md` و `tools/evidence_map.py` هستند. تغییر سورس برنامه نیازمند بازبینی محتوایی جداگانه است؛ اجرای دوبارهٔ مولد، موفقیت UI یا Backend را اثبات نمی‌کند. پس از آزمون واقعی، برگهٔ تکمیل‌شده را جدا نگه دارید؛ اجرای دوبارهٔ مولد، نسخهٔ خالی برگه را بازتولید می‌کند.
